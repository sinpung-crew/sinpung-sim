# 신풍승무 통합시뮬레이터 배포 저장소

서울교통공사 7호선 신풍승무 **구원운전 · MR관 파열조치 시뮬레이터**를
휴대폰 앱(안드로이드)과 웹 페이지로 배포하는 저장소입니다.

- 시뮬레이터 내용은 **비밀번호로 암호화**되어 올라갑니다. 저장소가 공개여도 비밀번호 없이는 내용을 볼 수 없습니다.
- 앱은 한 번만 설치하면 됩니다. 규정이 바뀌어 내용을 고치면, **앱을 켤 때 자동으로 최신 내용**을 받습니다.
- 바뀐 파일만 받기 때문에, 문구 수정 정도는 0.2MB 안팎만 내려받습니다.
- 한 번 받은 내용은 휴대폰에 저장되어 **인터넷이 없어도 실행**됩니다. (처음 한 번은 인터넷 필요)

## 폴더 구성

| 위치 | 내용 |
|---|---|
| `docs/index.html` | 웹 페이지 (비밀번호 입력 → 시뮬레이터 실행). 아이폰 사용자도 이 주소로 사용 |
| `docs/data/` | 암호화된 시뮬레이터 내용 (`manifest.json` + `f/*.bin`) |
| `android/` | 안드로이드 앱 원본 |
| `.github/workflows/build-apk.yml` | APK 자동 빌드 설정 |
| `tools/publish.py` | 시뮬레이터 HTML을 나누고 암호화해서 `docs/data/`에 넣는 도구 |

## 주소

- 웹 페이지: `https://<GitHub 아이디>.github.io/<저장소 이름>/`
- 앱 설치 파일: `https://github.com/<GitHub 아이디>/<저장소 이름>/releases/latest/download/sinpung-sim.apk`
  (안드로이드 휴대폰으로 웹 페이지를 열면 "안드로이드 앱 설치 파일 받기" 버튼이 보입니다)

## 규정이 바뀌어 내용을 고칠 때

1. 시뮬레이터 HTML 파일을 수정합니다.
2. 아래 명령으로 암호화 파일을 다시 만듭니다. (비밀번호는 기존과 같아야 합니다)
   ```
   pip install cryptography
   python tools/publish.py 신풍승무_통합시뮬레이터.html --note "6단계 고무마개 문구 수정"
   ```
3. 바뀐 `docs/data/` 를 GitHub에 올리면 1~2분 안에 웹 페이지와 모든 앱에 반영됩니다.

> 암호화 전 원본 HTML은 **절대 저장소에 올리지 마세요.** (`.gitignore`로 막아 두었습니다)

## 비밀번호를 바꿀 때

`--new-salt` 를 붙여 실행합니다. 모든 파일이 새로 암호화되므로 사용자는 앱에서 새 비밀번호를 한 번 입력하고 전체(약 28MB)를 다시 받습니다.

## 앱을 다시 빌드할 때

`android/` 를 고쳐서 올리거나, GitHub의 **Actions → 안드로이드 앱 빌드 → Run workflow** 를 누릅니다.
앱 서명 키는 저장소 Settings → Secrets and variables → Actions 의 `KEYSTORE_BASE64` 에 들어 있어야 합니다.
**서명 키 파일(sinpung-release.p12)은 따로 잘 보관하세요.** 잃어버리면 기존 앱 위에 새 APK를 덮어 설치할 수 없습니다.
