안드로이드 휴대폰은
구원GO 앱으로 보세요

앱을 설치하면 홈 화면 아이콘으로 바로 열리고, 인터넷이 없어도 실행됩니다. 규정이 바뀌면 앱을 켤 때 자동으로 최신 내용이 됩니다.

카카오톡 안에서는 설치 파일이 받아지지 않을 수 있어요. 인터넷 앱에서 설치 파일 받기 (안 되면 오른쪽 위 ⋮ → 다른 브라우저로 열기)
구원GO 앱 설치 파일 받기
설치 방법 보기
  1. 설치 파일 받기를 누릅니다. "유해할 수 있는 파일" 안내가 나오면 다운로드를 누릅니다.
  2. 다운로드가 끝나면 열기를 누릅니다.
  3. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아옵니다.
  4. 설치를 누릅니다. Google Play 프로텍트 안내가 나오면 세부정보 → 무시하고 설치를 누릅니다.
  5. 열기 → 비밀번호를 한 번 더 넣으면 내용을 받아 옵니다. (약 28MB, 와이파이 권장)

홈 화면에 아이콘이 없으면 앱 목록에서 구원GO신풍을 길게 눌러 홈 화면에 추가를 누르세요.

"자동 차단"으로 설치가 막히면: 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 끄고 설치한 뒤 다시 켜세요.

이미 앱을 설치했다면 홈 화면의 구원GO신풍 아이콘으로 여시면 됩니다.
